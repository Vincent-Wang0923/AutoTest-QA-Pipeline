# Test Cases: React + Flask Authentication Flow

## Conventions

- **Endpoints**: Registration uses `POST /api/register`; login uses `POST /api/login`.
- **RUN_ID**: A unique token injected per test run to keep usernames independent across runs.
- **Exact-length tokens**: `{{RUN_ID_6}}` denotes a username whose total length is exactly 6 characters.
- **Message assertions**: Only messages explicitly stated in the PRD are asserted verbatim.
